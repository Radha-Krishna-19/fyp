# Reference figures

Generated figures used by the site, the textbook and the panel deck, plus the
tooling that produces and verifies them.

| File | What |
|---|---|
| `make_figures.py` | Regenerates the data figures from the live pipeline. `--sync` copies them to `1_website/figures/` and `8_textbook/figures/`. |
| `verify_figures.py` | Proves every image in the repository was generated by our own code, and that duplicated copies have not drifted apart. |
| `PROVENANCE.md` | What produced each figure, from which input, and which ones cannot yet be regenerated with one command. |
| `fig03`, `fig04`, `fig07`, `network_analysis_figure` | The regenerable data figures. |
| `band77_figure.png` | The five-panel 77-framework result, from Step 11 of the analysis notebook. |

## Quick check

```bash
pip install numpy matplotlib
python verify_figures.py      # is every image ours?
python make_figures.py        # remake the data figures
```

`verify_figures.py` exits non-zero if any image lacks a matplotlib signature,
carries camera or image-editor metadata, or if two copies of the same figure
have diverged. It is the answer to "did you draw these yourselves or download
them?"
