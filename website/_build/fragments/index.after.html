0Where to Start

This site is a documentation portal rather than a poster. Each page is self-contained and can be read without prior context.

Methodology and architecture

The full workflow, the module architecture, the datasets and their provenance, the evaluation strategy, and the reasoning behind each design choice. Start here to assess the work.

The decomposition algorithm

The published metal-oxo algorithm, shown module by module, with the source code beside a live 3D model of the crystal it operates on. Four demonstration structures, and CIF upload.

From crystal to network

Every graph-theory term defined from first principles, then the periodic quotient graph, coordination numbers, centrality, defect simulation, and the Laplacian spectrum.

The multifractal spectrum

The published method this project builds on, the mathematics of τ(q) and f(α), and the definition error that silently invalidated every spectrum until it was found and corrected.

Results: the band, and its convergence problem

The 77-framework band, the confound analysis that ended the pore-size claim, the finite-size test that shows the band itself has not converged, and a plain statement of what this work does and does not establish.

Progress and deliverables

Who did what, an audited implementation-progress figure, instructions for reproducing every number from a clean clone, and where each deliverable is kept.
