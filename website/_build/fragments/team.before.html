0Reproducing Every Number

Nothing on this site is transcribed. Two independent routes regenerate all of it from a clean clone.

In the browser — no install

git clone https://github.com/Radha-Krishna-19/fyp.git cd fyp/website # then open index.html in any browser

Every asset is relative and three.min.js is vendored into the repository, so the site works from a local file with no web server and no internet connection. The network, spectrum and morphology-explorer numbers are computed at page load from the CIF files beside it; the other pages are generated from the result files by the scripts in website/_build/.

From the command line

cd fyp/code/spectrum_pipeline python code_00_pipeline_driver.py HKUST-1.cif python code_10_multifractal_spectrum.py # the 77-framework band: jupyter notebook ../notebooks/spectrum/mof_band_analysis.ipynb

The Python modules need the standard library, NumPy and NetworkX. The notebook writes results.json, which is the file band_data.js on this site is generated from.

Test suites

Twelve jsdom suites run the real pages headlessly and assert on computed output, not on markup. They are what catch a silently blank panel — a broken engine script throws no visible error, it just renders nothing.

cd fyp/website/tests npm install jsdom npm test
