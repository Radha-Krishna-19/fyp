This is not new bad news; it is old bad news finally measured. The convergence problem was present in every number this project published from the start — it was simply not tested until 2026-09-14/15. An earlier version of this page reported ~85% overall by weighting engineering and validation equally. That average hides a gating failure: a correctly engineered pipeline computing a descriptor that has not been shown to be a property of the framework is not 85% of the way to answering the project's question. It rules out the naive approach, which is a real result, but it is not the answer. What remains is either a size-independent redefinition of Δα (a fixed a-priori q range, a different partition-function normalisation, or reporting the Δα(D) growth slope itself as the descriptor) or a documented decision to retire Δα and report something else as the headline. Neither has been done.

3Reproducing Every Number

Nothing on this site is transcribed. Two independent routes regenerate all of it from a clean clone.

In the browser — no install

git clone https://github.com/Radha-Krishna-19/fyp.git cd fyp/1_website # then open index.html in any browser

Every asset is relative and three.min.js is vendored into the repository, so the site works from a local file with no web server and no internet connection. The numbers are computed at page load from the CIF files beside it.

From the command line

cd fyp/2_python python code_00_pipeline_driver.py HKUST-1.cif python code_10_multifractal_spectrum.py # the 77-framework band: jupyter notebook ../3_notebooks/mof_band_analysis.ipynb

The Python modules need the standard library, NumPy and NetworkX. The notebook writes results.json, which is the file band_data.js on this site is generated from.

Test suites

Nine jsdom suites run the real pages headlessly and assert on computed output, not on markup. They are what catch a silently blank panel — a broken engine script throws no visible error, it just renders nothing.

cd fyp/1_website/tests npm install jsdom npm test
