A metal–organic framework is a crystal built from metal clusters joined by organic struts. Hundreds of thousands of candidate structures exist; deciding whether one is worth making requires a molecular simulation that takes hours per structure. We ask a narrower, answerable question: can a descriptor computed from the framework's connectivity alone — in seconds, with no simulation — carry enough structural information to group frameworks usefully? We build the framework's periodic graph from its crystal structure, compute the multifractal spectrum of that graph, and reduce each framework to three numbers. Across 138 frameworks — 77 hypothetical and 61 that have actually been synthesised — those numbers form a narrow band, and the two sets land on the same band. We then test that band honestly, and report where it fails.

The descriptor transfers to real materials. The band was calibrated entirely on computer-generated frameworks. Sixty-one experimentally synthesised MOFs from CoRE MOF 2019, run through the identical pipeline, land at Δα = 0.95–1.47 against the hypothetical set's 1.02–1.41 — the same centre (means differ by 0.018, p = 0.38) and the same spectrum shape. This replaced an earlier claim, made from four structures, that the two sets did not overlap; that claim is withdrawn on the Results page along with the reason it was wrong.
The result we withdrew. Δα correlates with pore diameter at r = −0.497, which looked like a finding. Controlling for the number of blocks in the graph collapses it to r = +0.101, while graph size itself survives at +0.621, and adding pore size to a size-only model improves R² by 0.005. The descriptor was largely measuring how big the graph was. We removed that claim from the project rather than presenting it. The reasoning is set out in full in Results.
