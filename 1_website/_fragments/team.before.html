The claim we will make at review, and defend. The core pipeline is complete and integrated: a CIF goes in at one end and a validated three-number descriptor comes out at the other, demonstrated live in the browser and reproducible from the command line. That is the ~60% the rubric asks for at this stage, and the engineering table above puts it at 85%.

We report the two axes separately on purpose. A single number would let "we built a lot" stand in for "we established something", and those are not the same claim. The honest overall figure is about 73%, and the gap is entirely external validation — a data task, not a development task.
What would move the validation figure. One run: fifty CoRE MOF structures through the existing pipeline. It would settle family separation, settle whether the real-MOF gap is real, and give the band a meaning beyond one generator's output. Nothing needs to be built for it. That is why it is the top priority rather than any new feature.

0Reproducing Every Number

Nothing on this site is transcribed. Two independent routes regenerate all of it from a clean clone.

In the browser — no install

git clone https://github.com/Radha-Krishna-19/fyp.git cd fyp/metal_oxo_deep_dive/1_website # then open index.html in any browser

Every asset is relative and three.min.js is vendored into the repository, so the site works from a local file with no web server and no internet connection. The numbers are computed at page load from the CIF files beside it.

From the command line

cd fyp/metal_oxo_deep_dive/2_python python code_00_pipeline_driver.py HKUST-1.cif python code_10_multifractal_spectrum.py # the 77-framework band: jupyter notebook ../3_notebooks/mof_band_analysis.ipynb

The Python modules need only the standard library plus NumPy. The notebook writes results.json, which is the file band_data.js on this site is generated from.

Test suites

Five jsdom suites run the real pages headlessly and assert on computed output, not on markup. They are what catch a silently blank panel — a broken engine script throws no visible error, it just renders nothing.

cd fyp/metal_oxo_deep_dive/1_website/tests npm install jsdom npm test
