Results: The Band

The multifractal band across 77 frameworks, the size confound that killed the pore-size claim, and what survives.

What is and is not in this band. The band on this page is computed from the 77 hMOF frameworks only. HKUST-1, UiO-66, MOF-5 and ZIF-8 appear elsewhere on this site as demonstration structures for the decomposition algorithm and the network construction — they are not part of the band and are not plotted against it. Their unit cells hold 112–288 atoms against 3 000–6 600 for the frameworks here, which leaves too few distinct radii for a power-law fit to mean anything. Mixing the two would produce a chart that looks like a result and is not one.

1The Band — 77 Frameworks

Know what this dataset is. All 77 structures are named hMOF-### — they come from the hypothetical MOF database: computer-generated candidate structures that have never been synthesised. The notebook requested CoREMOF 2019, which is experimental, but the server returned hMOF records and nothing verified it. A check was added so this cannot recur silently.
  • Nothing here may be described as “experimental” or “real” — it is a computational screening library.
  • Every one of the 77 has a Zn₄O node, so the set is effectively single-metal. It cannot support any claim about behaviour across different metals, including the zirconium question.
  • What it is genuinely good for: one node type with many different linkers — a clean same-node, varied-linker family.

A band is the range of spectrum width Δα that a group of frameworks shares, so a new framework can be tested for membership. Scaling this to 77 frameworks exposed an error in how we were computing the spectrum, which is now fixed — and revealed that the band cannot yet be read as a chemical statement. Both are set out here.

The fix — the spectrum now has the right shape

A multifractal spectrum f(α) must be an inverted parabola whose peak sits at q = 0, where f(α0) = D0, the fractal dimension. Ours sloped downhill instead — a mathematics problem, not a materials result. With the corrected τ, all 77 frameworks now peak at q = 0.

The paper defines the mass exponent as a ratio:

τ(q) = ln 𝒫q(r) ⁄ ln(r⁄rN)

Over several radii that is a straight-line fit through the origin — the relation 𝒫q ~ (r/rN)τ carries no prefactor. Our code used np.polyfit(x, y, 1) and took the slope, which is a fit with a free intercept. At q = 0 that difference is fatal:

  • at q = 0 every term is pr_i^0 = 1, so 𝒫0 = |I|, the count of influential nodes;
  • that count is identical at every radius, so the free-intercept fit sees a flat line;
  • a flat line has slope zero, so τ(0) = 0, so f(α0) = 0·α − 0 = 0.

The peak is pinned to zero and the parabola disappears. Measured across the dataset: τ(0) = 0 and f(0) = 0 in all 77 frameworks, and not one of them peaked at q = 0. With the paper's definition ln(r/rN) < 0, so τ(0) = ln|I| / negative < 0 and f(α0) = −τ(0) > 0 — the peak returns.

What the band does — and does not — mean

All 77 spectra land in a tight band. The question is whether that band is telling us about chemistry. With published pore diameters available, it can be tested directly — and the answer is no, not yet.

The figure the notebook produces

Generated by Step 11 of mof_band_analysis.ipynb when you run it — the τ correction, the spectra, the band, and the size confound shown three ways.

What this leaves standing

  • The method is implemented correctly now. τ(q) matches the paper, the spectrum is a proper inverted parabola, and α0, the asymmetry A and D(q) are meaningful quantities for the first time.
  • The band exists as a descriptive range — the interquartile Δα across 77 frameworks. What it does not yet have is a demonstrated physical meaning.
  • Δα is not a stability or gas-uptake predictor. The graph is unweighted; it does not know which element an atom is.
  • What would make the pore claim testable: compare only frameworks of comparable graph size, or normalise the fit window per structure so Δα stops growing with the graph — then re-test the correlation.

Finding and reporting a confound in your own headline claim is a stronger position than presenting a correlation that does not survive the first check.

3The Same Analysis on Real, Synthesised MOFs

The band above is built from hypothetical frameworks. This section runs the identical pipeline on MOFs that have actually been made in a laboratory, expanded under the identical supercell rule so the two sets are comparable rather than differing by size.

What changed, and why it is a fair comparison. These four structures appear elsewhere on this site as small unit cells, used to demonstrate the decomposition. Here they are expanded under the same rule the 77 frameworks were expanded under — every lattice direction grown past 48 Å — which brings their block counts into the range the hMOFs occupy. Without that step the comparison would be measuring graph size, which is exactly the confound that removed the pore-size claim earlier on this page.

How to read this

Two readings are consistent with the gap, and the four structures here cannot separate them.

Reading 1 — the descriptor is working

hMOF structures are assembled combinatorially from a small library of building blocks into regular topologies, so their pore networks are unusually uniform. Real frameworks have more varied local environments, which is precisely what a wider singularity spectrum reports. On this reading Δα is measuring something chemically real, and the gap is the descriptor doing its job.

Reading 2 — four is not enough

Four structures chosen because they are famous are not a random sample of synthesised MOFs. All four are archetypes, picked for high symmetry and clean topology. It is possible that a broader sample of real frameworks would overlap the hMOF band after all, and that these four are simply unusual.

What this does establish, stated carefully. A band fitted on hypothetical frameworks would reject all four of these real materials. Whichever reading is right, that is a warning worth recording: a screening rule calibrated on generated structures cannot be assumed to transfer to materials that exist. Distinguishing the two readings needs a proper sample, which is the next section.

4Scaling the Comparison to Fifty Real Frameworks

Four synthesised structures show a clean gap. Four is not a sample. This is the concrete plan for turning that observation into a result, and the bug fix that unblocked it.

The bug that caused this in the first place

The analysis notebook was always written to pull CoRE MOF 2019 — experimentally derived, solvent-removed crystal structures. It asked the MOFX-DB API for exactly that. What came back was hMOF records, and that is why every quantitative result in this project has been computed on hypothetical frameworks.

The cause: on that endpoint the database= parameter is advisory, and when it is combined with a gases[] filter the gas filter wins. The request was correct; the response simply did not honour it. A provenance check further down the notebook caught the discrepancy and printed a warning — which is the only reason we know, rather than having published "experimental" results computed on generated structures.

Fixed. The fetch now filters every returned record on its own database field and discards anything that is not CoRE MOF, rather than trusting the server-side parameter. The limit was raised so that enough survive the filter, and the run prints how many records were streamed, how many were kept, and what was discarded. Asking politely is not a provenance guarantee; checking each record is.

What we predict, recorded before the run

If reading 1 holds

Fifty CoRE MOF structures of matched graph size cluster around Δα ≈ 1.7–2.3, above the hMOF band, and split by metal or by underlying net. That would make the gap a real property of synthesised frameworks and the descriptor genuinely informative.

If reading 2 holds

They scatter broadly and overlap the hMOF band, showing that our four archetypes were unrepresentative. We would report that, withdraw the gap the way we withdrew the pore-size claim, and say so on this page.

The procedure, which runs unchanged

Every module from bond perception onward is written per-CIF and is indifferent to where the CIF came from. No code change is required — only data.
