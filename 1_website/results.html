The band below has not converged, and should not be read as a structural result — for two independent reasons.

Reason 1: the wrong graph was measured. This site describes the spectrum as computed on the coarse-grained building-block graph. The 77-framework band on this page and the 61-framework real-MOF band referenced later were in fact both computed by running the analysis on the atomic supercell bond graph — coarse-graining only supplied the node/linker counts. An atomic MOF graph has two length scales: molecular, inside one linker or metal cluster, and framework, above one linker length. Fitting a single power law across that crossover, as both notebooks did, is not a valid scaling measurement regardless of how large the graph is.

Reason 2: on the graph the site actually describes, the descriptor still does not converge. A finite-size test on the coarse-grained quotient graph (2_python/code_12_converged_band.py, q_range_convergence()) grew the supercell of four demonstration frameworks — HKUST-1 (tbo), MOF-5 (pcu), ZIF-8 (sod) and UiO-66 (fcu) — and found Δα increasing at every graph diameter tested, at every cap on the distortion exponent q from |q| ≤ 10 down to |q| ≤ 2, with no plateau. The mechanism: at extreme q the partition function is dominated by a single box, the smallest possible box is one vertex, and that term grows with graph size without bound. Numbers and method: see the repository, CLAUDE.md and 2_python/code_12_converged_band.py.

Consequently: every Δα value published by this project is a function of the graph it was measured on, not of the framework it is attributed to, for both of the reasons above. This also explains the +0.62 correlation with graph size discussed below — it was not a confound contaminating the descriptor, it was the descriptor. Nothing here has been recomputed at a "converged" cap or a "correct" graph, because neither produces a value that has been shown to settle. A band is the range of spectrum width Δα that a group of frameworks shares, so a new framework can be tested for membership. Scaling this to 77 frameworks exposed an error in how we were computing the spectrum, which is now fixed — and revealed that the band cannot yet be read as a chemical statement. Both are set out here.

The fix — the spectrum now has the right shape

A multifractal spectrum f(α) must be an inverted parabola whose peak sits at q = 0, where f(α0) = D0, the fractal dimension. Ours sloped downhill instead — a mathematics problem, not a materials result. With the corrected τ, all 77 frameworks now peak at q = 0.

The paper defines the mass exponent as a ratio:

τ(q) = ln 𝒫q(r) ⁄ ln(r⁄rN)

Over several radii that is a straight-line fit through the origin — the relation 𝒫q ~ (r/rN)τ carries no prefactor. Our code used np.polyfit(x, y, 1) and took the slope, which is a fit with a free intercept. At q = 0 that difference is fatal:

  • at q = 0 every term is pr_i^0 = 1, so 𝒫0 = |I|, the count of influential nodes;
  • that count is identical at every radius, so the free-intercept fit sees a flat line;
  • a flat line has slope zero, so τ(0) = 0, so f(α0) = 0·α − 0 = 0.

The peak is pinned to zero and the parabola disappears. Measured across the dataset: τ(0) = 0 and f(0) = 0 in all 77 frameworks, and not one of them peaked at q = 0. With the paper's definition ln(r/rN) < 0, so τ(0) = ln|I| / negative < 0 and f(α0) = −τ(0) > 0 — the peak returns.

What this leaves standing

  • The mathematics of the spectrum is implemented correctly. τ(q) matches the paper's definition, the spectrum is a proper inverted parabola, and α0, the asymmetry A and D(q) are meaningful quantities for the first time — this is a real fix and stands independently of which graph the spectrum is taken on.
  • The band, as reported here, was computed on the wrong graph and has not converged even on the right one. The 77-framework interquartile range is a real computed quantity, but it describes the atomic supercell graph the pipeline happened to build, at the size it happened to reach, not a settled property of the frameworks. See the corrected withdrawal notice above for both reasons.
  • Δα is not a stability or gas-uptake predictor. The graph is unweighted; it does not encode which element an atom is.
  • What would make the descriptor usable: first, running the analysis on the coarse-grained quotient graph as the site describes, rather than the atomic graph the published numbers actually used; then either a size-independent definition of Δα on that graph — not found by narrowing the q range, so some other normalisation would be needed — or reporting the Δα(D) growth curve itself as the descriptor, rather than a single number. None of this has been implemented; all of it is open work.

Finding and reporting a confound, and later a non-convergence, in one's own headline claim is a stronger position than presenting a number that has not been checked this way.

The Full, Correct Band: Both Datasets on the Coarse-Grained Supercell Graph

Everything above this point used the atomic graph by mistake. This section redoes the analysis on the graph the method actually calls for — the coarse-grained supercell — on the complete 77-framework hMOF set and the complete 61-framework CoRE MOF set, not a sample of either.

A vertex here is one building block, not one atom. The unit cell is decomposed into blocks, joined into a labelled quotient graph (each edge carries the lattice translation it crosses), then that block graph is replicated n×n×n until every lattice direction reaches 48 Å — the same physical target the original notebooks used, applied to the correct graph this time. No atoms are built at any point, so replication is cheap and the graph reaches a real diameter. The full reasoning for why this is the right graph, and why the other three candidates (unit cell alone, atomic graph, coarse-grained unit cell alone) are each wrong for a different reason, is on the Methodology page.
All 77 hMOF and all 61 CoRE MOF structures were attempted. 72 hMOF and 55 CoRE MOF produced a usable spectrum; the rest were excluded because the graph diameter at this supercell size came out below 8, which is too small to fit a scaling law over (the same gate code_12_converged_band.py already enforces). One spectrum per structure, one random seed, 20 box-covering trials — not the multi-seed average used for the single-structure convergence figure earlier on this page, so there is no per-structure error bar here to check the resulting classes against. That limitation is real and is not hidden in what follows.
Two parameters remain once the graph itself is fixed: which vertices count as influential, and how far out the radius window is fitted. Influential = top 20% of vertices by degree. A MOF's coarse graph is a small population of high-degree metal-cluster vertices wired to a much larger population of low-degree linker vertices. Too narrow a cut (say, top 10%) keeps too few vertices to average a box-covering measurement over reliably; too wide a cut (30% or more) starts pulling in ordinary linker vertices whose local growth looks like everyone else's, diluting the signal the metric is meant to isolate. 20% sits inside the structural core without diluting into the bulk. Radius window = half the diameter, not the full diameter. Box-covering partitions the graph into boxes of a given radius; near the full diameter, only one or two giant boxes can fit, so a single random covering trial decides the point almost by itself. Radii out to half the diameter keep every fitted point in the range where several boxes still exist to average over. Checked directly on all four demonstration nets (2_python/_test_window_frac.py): the narrower window makes Δα's growth with supercell size gentler at every step tested (slope vs ln(diameter) 0.63–0.79, against 0.73–0.91 at the full diameter), though the quantity still grows with size under either window rather than settling to a constant. The graph itself is unaffected by either choice — that question is settled separately, see the callout above.

Does class membership track graph size here too?

The earlier finding on this page used a smaller sample and the wrong graph. Repeated on the full datasets, on the correct graph, the answer is the same.

Using the correct graph fixes the graph. It does not fix the descriptor. The earlier finding on this page — that Narrow/Medium/Wide tracked coarse-grained graph size rather than chemistry — was demonstrated on 34 hMOF structures using an independent supercell construction. Repeating it on the complete 77+61 structures, using this project's own correct coarse-grained supercell graph, gives the same answer: r = +0.69 (hMOF) and +0.72 (CoRE MOF) with node count. This is a second, independent reason Δα cannot be used as published, on top of the non-convergence already established: even where the graph is right, the descriptor still separates frameworks mostly by how large the analysed graph happens to be.

Two separate findings, and they point the same way for different reasons. Where the coarse-grained graph genuinely differs in size between structures, class membership is completely explained by that size — not partially, not mostly, completely, for every one of the 13 distinguishable groups in this sample. Where the coarse-grained graph is identical — the majority case, 48 of 76 structures — class membership is decided by something coarse-graining cannot see at all: box-covering trial noise on a descriptor (Δα) already shown elsewhere on this page not to converge with size. Neither case supports reading Narrow/Medium/Wide as a chemical or structural distinction. In the first case the label restates a number already reported (node count); in the second it restates nothing, because the input to the classifier is uninformative by construction.
Why coarse-graining cannot see the difference among the 48. Coarse-graining collapses every atom in a building block to one vertex and keeps only which blocks are bonded to which. The 48 hMOF structures in this group are built from the same net (pcu), the same node (Zn₄O), and differ only in linker chemistry — which SMILES string the organic strut is. That is exactly the information coarse-graining discards by design (see the Methodology page's discussion of which graph the spectrum is taken on). A method that cannot see linker chemistry cannot separate frameworks that differ only in linker chemistry, and it does not: it produces the same graph, computes the same statistics, and any apparent difference in the resulting Δα is measurement noise.

Does the Divergence Slope Itself Vary Between Frameworks? A Proposal, Not a Result

The Methodology page lists reporting the Δα(D) growth slope as one of two ways forward once the width itself is known not to converge. This section takes a first, capped look at whether that slope actually differs between frameworks, using a smaller sample than the full analysis above — which it would have to differ, to be worth proposing.

What was run, and what was not. Twenty structures per dataset, chosen for size spread rather than sampled at random or taken in full. Supercell replication capped at 5000 nodes. A three-point sweep (n = 2, 3, 4) with one seed, not the five-point, three-seed sweep used for the single-structure convergence figure earlier on this page — enough to fit one slope per structure, not enough to know that slope precisely. This trades per-structure precision for coverage across many structures on purpose: the question here is whether the slope varies between frameworks at all, not what any one framework's slope equals to three decimal places. Several structures were dropped where the size cap left fewer than two usable points (2_python/code_15_dataset_sweeps.py reports each one).
The slope varies about 2.5× more across CoRE MOF than across hMOF, at this sample size and this precision. That is consistent with the slope carrying real structural information the width does not — the hMOF set is dominated by one degenerate, repeated topology (confirmed on the full dataset above), so a tight slope distribution there is exactly what a topology-driven slope should look like, while CoRE MOF's real topological variety would be expected to spread the slope out. It is also consistent with the CoRE MOF spread being sampling noise from the coarser, one-seed, 20-structure sweep; nothing here distinguishes those two explanations, and doing so needs the same multi-seed, full-sweep rigour code_12 applies to one structure at a time, run across many. This is a candidate worth pursuing, stated as one, not a second descriptor to add to the withdrawn list above.

Why this is the question that matters. Every quantitative result on this page above this point was computed on hMOF-### entries: chemically plausible, combinatorially assembled, never synthesised. A band that only holds for one generator’s output is a statement about that generator, not about matter. The only way to tell the difference is to run the same code on structures that came out of a laboratory — enough of them to be a distribution rather than an anecdote.
Everything below this point compares two bands that are both withdrawn. As set out above, Δα does not converge with supercell size on the coarse-grained quotient graph, and both this 61-framework band and the 77-framework hMOF band were in fact computed on the atomic supercell graph, not the coarse-grained graph this site describes — which additionally spans two length scales (molecular and framework) that a single power-law fit cannot legitimately span. The comparison below is kept, with this notice, because the question it asks — does a band calibrated on one dataset transfer to another — is a reasonable one to have asked, and the negative answer about convergence does not depend on which dataset the non-converged number came from. Read every number below as “two non-converged quantities agree with each other”, not as a chemical or structural finding.

What this used to say, and why it is weaker than it looks now. This section previously read “the descriptor transfers” — a quantity calibrated on generated structures landing in the same place on structures people actually made. That agreement is still a true observation, but both quantities being compared are the same non-converged, size-dependent number computed on the wrong graph (see the withdrawal notice above). Two artefacts of the same computational choice agreeing with each other is not evidence that a screening rule transfers between hMOF and real materials; it only shows the artefact is not specific to one dataset.

4Both Bands, Stated Exactly — and What a Band Is Actually For

The word “band” has been used loosely on this page. Here it is pinned down: three different definitions, the numbers for each dataset under each, and an honest account of what such a band can and cannot be used for.

You know
That both sets of frameworks produce spectrum widths in the same region — and that both are withdrawn as structural findings.
This section
States each band precisely under three definitions, for the record, and sets out what a band of this kind could be used for if a converged version existed.
Which lets us
Say what this project would deliver if the descriptor were fixed, without pretending the numbers below are usable today.
The table and the four uses below describe both bands as they were computed — which is to say, as artefacts. Kept for the record and to make concrete what “a band” would look like if Δα converged. None of the four uses below is actually available today; the fourth was already marked unsupported before this withdrawal, and the withdrawal removes the other three as well.

First: “band” is three different claims

A range can be quoted as the full extent of the data, as the middle half, or as a central interval that discards the tails. They are not interchangeable, and quoting one while implying another is a standard way to overstate a result. All three are given below so the reader can pick.

Real frameworks are more varied than generated ones — which is the expected direction, and worth stating because the usual worry runs the other way, that a hand-curated set will be artificially narrow.

What a band is for — four uses, none of them currently supported

1. A null range not supported

You cannot call a framework “unusually heterogeneous” without knowing what usual is, and a band would supply that reference — if it were a property of the frameworks rather than of the graph it happened to be measured on. Since Δα drifts with supercell diameter without bound, there is no fixed “usual” to compare a new structure against; the answer would depend on how large a graph the new structure's pipeline run happened to build.

2. Pipeline quality control partially usable

A framework whose spectrum fails to compute at all, or whose linearity R² collapses, still flags a broken CIF or a disconnected supercell — that check does not depend on Δα being converged. But using a specific Δα range as the flag (as the 39 rejected structures in this run were) is not defensible until the range is defined at a fixed, stated graph size.

3. Transfer from cheap data to real materials not supported

The two bands coinciding was read as evidence that a rule calibrated on hMOFs applies to real MOFs. It is now understood as two copies of the same size-dependent artefact agreeing with each other — unsurprising, since both were computed the same way on graphs of overlapping size. This does not establish transfer.

4. Screening candidates not supported

The aspiration is to triage candidates before spending hours of simulation on them. That requires Δα to correlate with a property someone wants, and nothing here demonstrates that — and it requires Δα to be a fixed number for a given framework in the first place, which the convergence finding above shows it is not. This use was already unsupported before the withdrawal; the withdrawal removes any route to supporting it without a redefinition of the descriptor.

How discriminating is the band, really? The question is moot: a band expressed as a fixed numeric range (such as the combined interquartile band 1.10–1.26 quoted in the table above) is not well-defined once Δα is shown to depend on supercell diameter without bound. Any pass/fail threshold quoted from this table describes the sample that was measured, at the graph sizes it happened to be measured at, not a property a new structure can be checked against.
This page previously gave a rule of thumb for reading a new framework's Δα against the band above. That rule is withdrawn along with the band it was based on. Until a size-independent descriptor is defined and its own reference range is measured, there is no number this project can responsibly hand you to compare a new CIF's Δα against.

5How Those Sixty-One Frameworks Were Obtained

The route to real structures had to be rebuilt twice: once because the database returned the wrong records, and once because the service stopped returning records at all.

You know
That the two bands coincide.
This section
Explains where those 61 real structures came from, and the two separate failures that made getting them hard.
Which lets us
Judge the provenance of the data, which is the part most easily faked and least often shown.

The bug that made this necessary

The analysis notebook was always written to pull CoRE MOF 2019 — experimentally derived, solvent-removed crystal structures. It asked the MOFX-DB API for exactly that. What came back was hMOF records, and that is why every quantitative result in this project was, for months, computed on hypothetical frameworks.

The cause: on that endpoint the database= parameter is advisory, and when it is combined with a gases[] filter the gas filter wins. The request was correct; the response simply did not honour it. A provenance check further down the notebook caught the discrepancy and printed a warning — which is the only reason we know, rather than having published “experimental” results computed on generated structures.

Then the API stopped answering entirely. The corrected query — which filters every returned record on its own database field rather than trusting the server — began returning zero records. A query that returns nothing is at least honest, but it does not produce a dataset.
Fixed by removing the dependency. The structures now come from the Zenodo archive of CoRE MOF 2019, DOI 10.5281/zenodo.3370236, downloaded by DOI rather than queried. An archived record is immutable and citable: it is the same bytes for every reader, permanently, which is a stronger provenance guarantee than any live endpoint can offer. Sampling is capped per metal composition so that no single metal can dominate the set the way Zn dominated the 77.

The procedure, which ran unchanged

Every module from bond perception onward is written per-CIF and is indifferent to where the CIF came from. Moving from hypothetical to real structures required no change to the analysis — only to the source of the data. That is worth stating plainly, because it is the reason the two sets are comparable at all.

The descriptor separates structures reliably and reproducibly, but nothing here shows it predicts a property anyone wants — uptake, selectivity, stability. The honest status is that we have a well-behaved, size-confounded-checked structural descriptor with no demonstrated application, and the next real test is regression against a measured adsorption property on this same set.
