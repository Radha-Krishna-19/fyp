# Crystal structures

| Folder | Files | Source | Note |
|---|---|---|---|
| [`hmof/`](hmof/) | 77 CIF files, `hMOF-<id>.cif` | MOFX-DB (hypothetical MOFs of Wilmer et al., 2012), returned for a query that asked for CoRE MOF 2019 with xenon isotherms | Hypothetical structures; all share the Zn<sub>4</sub>O node |
| [`core_mof_2019/`](core_mof_2019/) | 61 CIF files | CoRE MOF 2019 (Chung et al., 2019), experimentally synthesised structures | `_clean`, `_manual` and `_charged` suffixes are those of the CoRE MOF archive |

The provenance check that found the hMOF/CoRE MOF mismatch is described in the
[team paper](../../docs/paper/G070_Paper.pdf) (Section III) and on the
[Results page](https://radha-krishna-19.github.io/fyp/results.html).
