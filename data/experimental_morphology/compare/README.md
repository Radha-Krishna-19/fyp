# Models against experiment

| File | What it does |
|---|---|
| `COMPARISON.md` | Written comparison of every shape model with the laboratory records |
| `comparison.csv` | The same comparison as a table |
| `compare_with_project.py` | Scores the project's models against `../dataset/experimental_morphology.csv` |
| `add_chgnet.py` | Adds the CHGNet model to the comparison |
| `keerthi_vs_lab.py`, `keerthi_vs_lab.json` | The condition-based model of Keerthi against the laboratory records |
